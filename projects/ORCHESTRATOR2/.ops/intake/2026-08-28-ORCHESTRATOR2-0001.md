--------------------------------------------------
GAUGE 1 — PROJECT HEALTH
--------------------------------------------------

Calculate an overall project-health score.

Initial heuristic:

Start at 100.

Subtract:
- blocked task: -10 each
- failed task: -15 each
- overdue task: -5 each
- unresolved approval/clarification older than configured threshold: -5 each

Clamp:
0–100

Display:

Overall Project Health
87%

Status ranges:

90–100  HEALTHY
70–89   WATCH
50–69   AT RISK
0–49    CRITICAL

Make weighting/configuration easy to change later.

Do not pretend this is AI-derived project health.

Label it clearly as a calculated operational health score.

completed committed tasks
/
